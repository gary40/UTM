## 一、正式組織圖（部門制）

```
總經理室
├─ 人才資源部（人資與系統 MIS）
│  ├─ 選才任用・教育訓練・薪酬福利・績效管理・員工關係
│  └─ 系統維護：帳號權限、設備管理、人資系統
├─ 行政管理部（採購／行政／專案）
│  ├─ 財務管理：會計・出納・稅務
│  ├─ 產品管理：新品選品、供應商開發、上市專案、市場管控
│  ├─ 採購與進口管理：國外原廠採購、進口報關
│  ├─ 專案管理・供應商合約
│  └─ 總務行政・會議管理・後勤支援
├─ WEiZ 營運部
│  ├─ 後勤：櫃位供貨、採購與電商營運、供應商管理、營運管理（選品上架／業績分析）、行銷活動（會員・OMO・活動・社群）、品牌與展店企劃
│  └─ 現場：櫃位管理（嘉義・高雄・台中）、櫃位人員培訓
├─ 售後品保部
│  ├─ 倉儲管理：內倉／外倉庫存、代理商品倉管、進出貨與物流對帳
│  ├─ 顧客服務：各通路客訴、訂單追蹤、客服 LINE @weibo
│  └─ 售後產品檢測：退換貨檢測、故障分析、維修與整新
├─ 行銷業務部
│  ├─ 品牌行銷推廣：口碑經營・網路流量・社群行銷・KOL 體驗邀約・商務合作・公關媒體經營
│  └─ 經銷業務合作：連鎖通路經銷・各區域經銷商・團購經銷・企業禮贈品經銷
└─ 電商通路部
   ├─ 平台營運：momo／PChome／蝦皮／Pinkoi／Yahoo／WEiZ 購物商城
   ├─ 數位行銷：站內廣告、SEO、社群
   └─ 訂單履行：撈單出貨（D+1）、對帳與損益
```

### 關於「營運管理 C／D／E」

2026-09-10 的說明文件寫道：原件《威柏科技＿組織架構圖＿2026.07》在 WEiZ 後勤下列有「營運管理 A／B／C／D／E」五項；A 是「新品選品上架、樣品申請、系統活動設定」，B 是「業績分析」，**C／D／E 三項的細項文字在原件中有疑義，整理者未展開，也沒有猜測內容**。原件目前不在我能讀取的 Drive／Notion 範圍內。處理建議：在部門制版本中，WEiZ 後勤的職掌已用「營運管理（選品上架／業績分析）」概括，C／D／E 不再出現；若原件另有明確項目（例如會員經營、櫃位陳列、庫存調撥），請提供原件或直接告訴我名稱，我再補回。

## 二、系統架構（功能分層）

同層並列不代表已自動串接；箭頭只列既有架構文件記載的主要資料方向。

| 層 | 系統 | 用途 |
|---|---|---|
| 顧客與交易入口 | WEiZ 商城（Cyberbiz） | 線上購物／會員 |
| | Cyberbiz POS | 門市結帳 |
| | WEIBO 官網 | 保固／維修／經銷服務 |
| | LINE OA ＋ LIFF | 顧客溝通、會員入口、銷售宇宙手機入口 |

| | **WEiZ 銷售宇宙** | 三櫃業績／班表／日誌／任務／公告／權限 |
| 文件與協作 | CubeLV（含文件收件匣） | 管理筆記、專案、插件與 AI 員工；文件審查、編號與定稿 |
| | Notion | 團隊共編、會議紀錄、定稿登記 |
| | Synology NAS | 文件／素材儲存與備份 |
| | WEiZ 知識庫 | 門市操作與訓練（HTML） |
| | WEiZ 社群成效追蹤 | 貼文資料與前台成效 |
| | NUEiP | 人資考勤 |
| | EVOX 雲端總機 | 電話與分機 |

### 主要業務資料流

| 來源 | → | 目的 | 內容 |
|---|---|---|---|
| T8 ERP | → | 商城／官網 | 商品代碼與首次建檔 |
| WEiZ 商城 | → | T8 ERP | 付款成功訂單 |
| T8 ERP | → | WEiZ 商城 | 出貨與物流資訊 |
| 商城 → T8 ERP | → | 官網 | 會員資料 |
| WEIBO 官網 | → | T8 ERP | 維修完成後出入庫單（人工確認過帳） |
| Cyberbiz POS | → | WEiZ 銷售宇宙 | 成交資料（手動同步） |

**必要區分**：商城可售量、POS 成交與 T8 實體庫存是三筆不同的資料；既有文件不支持「三者已全面即時同步」的說法。

## 四、文件編號與檔名規則

**文件編號**由 CubeLV 文件收件匣於定稿時賦予，模板上只保留欄位與格式提示。依「文件定稿交件中心」既有紀錄整理：

| 文件類型 | 格式 | 範例 |
|---|---|---|
| 合約、經銷／授權合約 | `CON` + 年月日 6 碼 + 流水 2 碼 | CON26082801 |
| 公文 | `PM-` + 年月日 8 碼 + 流水 2 碼 | PM-2026082601 |
| 報價／報表、其他 | `DOC-` + 年月日 8 碼 + `-` + 流水 2 碼 | DOC-20260807-02 |

（另有早期編號 BB009001 一筆，屬舊制。）

**檔名**依「產出品質九條」第 7 條：文件、報告、簡報用 `YYYYMMDD_部門_主題_v版本`，例 `20260910_行政_WEIBO報價單模板_v2.docx`；品牌素材用 `檔期_平台_尺寸_版本`。修改後升版本、不覆蓋舊檔。

資料依據：威柏全系統架構總覽（內文更新 2026-08-17）、WEiZ & 威柏會員資料體系規範、文件定稿交件中心（Notion）。**帳號與密碼不記載於任何品牌文件。**
