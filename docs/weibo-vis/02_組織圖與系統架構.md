### 待核對

1. 營運手冊 V1.0 的**部門制**（人才資源部、行政管理部、品牌營運處下轄 WEiZ 營運部／售後品保部／行銷業務部／電商通路部）與本**職能架構**是兩種切法，正式對外組織圖需擇一。
2. 營運管理 C／D／E 細項。
3. 「客服與商品保」是否定名為「售後品保部」。

## 二、系統架構（功能分層）

同層並列不代表已自動串接；箭頭只列既有架構文件記載的主要資料方向。

| 層 | 系統 | 用途 |
|---|---|---|
| 顧客與交易入口 | WEiZ 商城（Cyberbiz） | 線上購物／會員 |
| | Cyberbiz POS | 門市結帳 |
| | WEIBO 官網 | 保固／維修／經銷服務 |
| | LINE OA ＋ LIFF | 顧客溝通、會員入口、銷售宇宙手機入口 |
| 核心營運 | **T8 ERP（正航）** | 進銷存／採購／帳務／商品主檔 |
| | **WEiZ 銷售宇宙** | 三櫃業績／班表／日誌／任務／公告／權限 |
| 文件與協作 | CubeLV（含文件收件匣） | 管理筆記、專案、插件與 AI 員工 |
| | Notion | 團隊共編、會議紀錄、定稿登記 |
| | Synology NAS | 文件／素材儲存與備份 |
| | WEiZ 知識庫 | 門市操作與訓練（HTML） |
| | WEiZ 社群成效追蹤 | 貼文資料與前台成效 |
| | NUEiP | 人資考勤 |
| | EVOX 雲端總機 | 電話與分機 |

### 主要業務資料流

| 來源 | → | 目的 | 內容 |
|---|---|---|---|
| T8 ERP | → | 商城／官網 | 商品代碼與首次建檔 |
| WEiZ 商城 | → | T8 ERP | 付款成功訂單 |
| T8 ERP | → | WEiZ 商城 | 出貨與物流資訊 |
| 商城 → T8 ERP | → | 官網 | 會員資料 |
| WEIBO 官網 | → | T8 ERP | 維修完成後出入庫單（人工確認過帳） |
| Cyberbiz POS | → | WEiZ 銷售宇宙 | 成交資料（手動同步） |

**必要區分**：商城可售量、POS 成交與 T8 實體庫存是三筆不同的資料；既有文件不支持「三者已全面即時同步」的說法。

## 三、系統名稱與用途

| 名稱／別名 | 用途 | 主要使用者 |
|---|---|---|
| T8 ERP／正航 ERP／T8 | 商品代碼與首次建檔、採購、入出庫、調撥、盤點、客戶供應商及財務帳務管理 | 全公司 |
| WEiZ 商城／WEiZ EC | WEiZ 線上銷售通路：商品頁、售價、會員、購物、優惠、訂單與線上可售量 | WEiZ 後勤 |
| Cyberbiz／CBZ | WEiZ 商城使用的電商平台；不是另一套獨立商城 | WEiZ 後勤 |
| Cyberbiz POS／WEiZ POS | 實體門市結帳：交易、會員、結帳人員與優惠券使用 | WEiZ 現場 |
| WEIBO 官網 | 品牌產品展示、保固登錄、維修申請與查詢、經銷商帳號與訂單服務 | 客服與商品保、經銷業務 |
| WEiZ 銷售宇宙 | 三櫃營運管理後台：業績、班表、工作日誌、任務、公告、目標與角色權限；成交來源為 Cyberbiz POS，不負責 ERP 扣庫 | WEiZ |
| LINE OA | LINE 官方帳號，品牌與顧客溝通及會員入口 | 客服、行銷 |
| LINE LIFF | LINE 內開啟網頁應用的技術；銷售宇宙已整合為手機入口 | WEiZ 現場 |
| CubeLV | 管理筆記、檔案、待辦、專案、插件與 AI 員工的工作平台 | 管理層、各部門 |
| 文件收件匣 | 接收送件、文件審查與定稿處理，銜接文件登記及歸檔 | 行政管理 |
| Notion | 團隊文件、會議紀錄、定稿登記與社群內容共編 | 全公司 |
| Synology NAS | 內部文件與素材集中儲存、共享、共編及備份 | 全公司 |
| WEiZ 知識庫 | 門市新人訓練、產品與操作手冊的 HTML 閱讀入口 | WEiZ 現場 |
| WEiZ 社群成效追蹤工具 | 管理貼文資料與公開前台成效，供社群追蹤、共編和週報使用 | 行銷 |
| NUEiP | 人資考勤：打卡、請假、福利假申請 | 全公司 |
| EVOX 雲端總機 | 公司電話與分機、客服來電 | 全公司 |

資料依據：威柏全系統架構總覽（內文更新 2026-08-17）、WEiZ & 威柏會員資料體系規範。未確認上線的規劃項目不列入。**帳號與密碼不記載於任何品牌文件。**
