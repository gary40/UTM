## 4. Logo

標誌 = 兩片藍色葉形（`#0000FF` 帶 68% 透明，白底呈現約 `#5252FF`）＋ 兩顆灰色圓點（`#666666` 帶 68% 透明，白底呈現 `#979797`），對角交錯、交疊處半透明。字標 WEIBO 粗體大寫。

**不變**：標誌顏色、比例、相對位置。**可變**：WEIBO 字標與中英文公司名可依背景選黑或白。標誌放在深底會略暗，是設計原意，不要改色去「修正」。

| 版型 | 檔名 | 用途 | 螢幕最小高 | 印刷最小高 |
|---|---|---|---|---|
| ① 完整直式 | `weibo_full_stacked_black/white` | 封面、官網、看板 | 80px | 20mm |
| ② 完整寬版 | `weibo_full_wide_*` | 大尺寸輸出、展場 | 80px | 20mm |
| ③ 公司名直式 | `weibo_corp_stacked_*` | 正式文件、證書 | 64px | 15mm |
| ④ 公司名橫式 | `weibo_corp_horizontal_*` | 文件表頭、信紙、Email 簽名 | 28px | 8mm |
| ⑤ 中文橫式 | `weibo_zh_horizontal_*` | 公文、箱貼、封箱膠帶 | 28px | 8mm |
| ⑥ 英文橫式 | `weibo_en_horizontal_*` | 網站 header、簡報內頁左下、社群頭像 | 28px | 8mm |
| 標誌單獨 | `weibo_logomark.png` | favicon、頭像、App icon、Loading、頁尾小圖 | 24px | 6mm |

- 安全距離：標誌高度的 ½，四周皆同；範圍內不得有文字、線條、其他 Logo、紋樣。
- 標誌單獨使用限上述用途，四周留白 ≥ 標誌高 20%，不得加框、陰影或改色。
- 排版時優先用 `assets/logos/cropped/`（已去透明邊）；原檔為 900×900 正方畫布。
- 八大禁止：拉伸壓縮、改標誌藍灰或把文字換成黑白以外顏色、移動旋轉葉形與圓點、加外框描邊陰影光暈漸層、放低對比或花俏背景、拆開標誌與字標另排、用其他字型重打 WEIBO、在標誌旁加吉祥物或裝飾。
- 現有檔皆為 PNG；展板、招牌、車體等大圖輸出前須取得向量檔（v1.1 待辦）。

## 5. 色彩

### 比例 70 / 20 / 10
70% 白／`#F4F4F8`；20% 主色 `#5D59FF`；10% Navy `#1E2A5E` 與灰。不用促銷紅、金；不用 WEiZ 的暖色點綴。

### 核心色

| 名稱 | HEX | 用途 |
|---|---|---|
| White | `#FFFFFF` | 主要背景 |
| Gray 50 | `#F4F4F8` | 次要背景（偏冷） |
| **WEIBO Blue** | **`#5D59FF`** | 主色（與 WEiZ 共用）、標題強調、表頭、CTA |
| WEIBO Navy | `#1E2A5E` | 深底、封面、頁尾、104 封面 |
| Logo Gray | `#979797` | 標誌灰，不另作 UI 色 |
| Gray 400 / 600 / 900 | `#999999` / `#666666` / `#333333` | 說明文字 / 次要文字 / 主要文字（禁純黑） |
| Card Teal | `#4DAAC0` | **名片專用**，其他一律不用 |

### 藍色階（與 WEiZ 相同）

`#EEEEFF` 50 淡填充 ・ `#D6D5FF` 100 hover 底 ・ `#A3A3FF` 200 ・ `#837FFF` 300 ・ `#5D59FF` 500 主色 ・ `#4A46E6` 600 hover ・ `#3A37C2` 700 press ・ `#1E2A5E` 900 Navy

### 功能色（只用在狀態與資訊）

綠 `#1E9E6A` 成功／現貨 ・ 琥珀 `#E8A317` 注意／待處理 ・ 紅 `#D93A1F` 錯誤／停產 ・ 藍 `#3C62EF` 連結

### 漸層

- 品牌漸層：`linear-gradient(135deg,#5D59FF 0%,#3A37C2 50%,#1E2A5E 100%)`，只用於封面、Hero、104 封面、信封背面、結尾頁。
- 輔助淺漸層：`linear-gradient(135deg,#EEEEFF,#D6D5FF)`。
- 禁止：按鈕漸層、文字漸層（僅簡報章節數字例外，用 `#8B7CFF→#5D59FF` 半透明）、疊在照片或 Logo 後方。

### 印刷

CMYK／Pantone 尚未由設計師確認，印刷品標「輸出 CMYK 未定稿」；名片以 AI 檔內 CMYK 為準。

## 6. 字體與排版

| 用途 | 字型 |
|---|---|
| 英文・數字 | Inter 400/500/700（表格數字加 `tabular-nums`） |
| 繁體中文 | Noto Sans TC 300/400/500/700 |

| 禁用 | 明體／宋體、標楷體、Logo 字標字型 |

字級：Hero 48–56 / H1 36 / H2 26 / Body 16 / Caption 13。標題 700，內文 400，行高 1.6。
眉標：英文全大寫，`letter-spacing .12em`（文件）至 `.3em`（簡報封面）。
中英混排：英文前後半形空格；型號不加空格（Type-C、20000mAh）；數字用 Inter／Arial。

## 7. 空間與版面

- 基礎單位 X = 25px；所有間距為其倍數（12.5 / 25 / 50 / 100 / 200）。
- 數位邊距 50px、容器 1200px、12 欄格線。
- A4 商務文件：邊距上 27（含表頭）／下 18／左右 20mm。
- 簡報 16:9：13.33×7.5in，邊距 0.6in。
- 圓角：圖示 2px、表格與輸入框 8px、按鈕 12px、卡片 16px。
- 陰影：中性淺灰；簡報卡片用淡紫 `rgba(93,89,255,.10)` 模糊 14。不用有色光暈（網站主 CTA 除外）。
- Logo 位置：左上或左下。**不放右下**（WEiZ 慣例，避免混淆）。

## 8. 版面語言

### 簡報（PPTX）
- 封面／結尾：品牌漸層底＋右上白色波紋線稿；眉標 `#D6D5FF` 字距 .3em；標題 40pt 白；⑥ 英文橫式白字 Logo 左下。
- 內頁：`#F6F6FF→#FFF→#F3F3FC` 對角淡紫底＋右上紫色波紋；左上漸層斜體數字（高 1in）＋斜線＋眉標「ENGLISH｜中文」13pt `#8B8BC8`＋斜切線；標題 28pt 粗體主色。
- 元件：白色圓角卡（0.75pt `#ECECF8` 邊、圓角 0.16in、淡紫陰影）；圓形圖示（0.56in 圓 `#EEEEFF`，Lucide 線條 1.75px 主色）；膠囊標籤（主色外框）；強調卡改主色底白字；表格表頭主色、奇偶列 `#F7F7FD`。
- 頁尾：⑥ 英文橫式黑字 Logo 左下高 0.3in；右下頁碼膠囊「Page 02 / 10」`#EEEEFF` 底主色字。
- 每頁至少一組圖示、卡片或表格；不做純文字頁；不用標題底線、彩色側邊條。

### 文件（DOCX／A4）
- 表頭每頁：左 ④ 公司名橫式黑字 Logo 高 9mm；右兩行灰色英文全大寫 6.5pt 字距 .12em（公司英文名／文件類型，如 CONFIDENTIAL - CONTRACT DOCUMENT）；下方 0.5pt `#D6D5FF` 線。
- 標題 20pt 粗體主色，靠左。
- 文件資訊表：兩欄，左欄 42mm 灰底 `#F4F4F8` 灰字，右欄黑字；列：編號、版本、發文部門、日期、有效期或機密等級。
- 章節標題 11pt 粗體主色；內文 9pt `#444` 行距 1.5；列點主色圓點。
- 品項表：表頭主色底白字，數字右對齊千分位，奇偶列 `#F9F9FE`，只保留橫線。
- 簽署欄：兩欄表格，表頭主色，列：公司、代表人、統編、簽章／用印、日期（西元）。
- 頁尾每頁：0.5pt `#D6D5FF` 線；左標誌小圖＋文件說明 6.5pt 灰；右「第 N 頁」。
- 合約與含金額文件：「機密 CONFIDENTIAL」水印，主色 7% 透明，旋轉 32°，置中，每頁（`assets/brand/watermark_confidential.png`）。報價單不加。

### 印刷與其他應用
- 信紙：與文件同表頭；信封 DL 220×110，正面白底 ④ Logo，背面品牌漸層＋白色波紋＋⑥ 白字 Logo。
- 箱貼 100×70mm：頂端 3mm 主色帶（單色版省略）、⑤ 中文橫式 Logo、欄位品名／品號／數量／箱號／出貨日／客戶通路、QR 位、「易碎 FRAGILE」；不留平台貼紙空白。
- 封箱膠帶 48mm：A 款主色底 ⑥ 白字重複；B 款透明或白底 ⑤ 黑字。
- 104／LinkedIn 封面：品牌漸層＋波紋；眉標 WE EMPOWER INNOVATION、⑥ 白字 Logo、企業標語；頭像用標誌單獨檔。
- 名片：一律以 `templates/business-card/WEIBO_名片_印刷檔.ai` 輸出，只換六個文字層；配色深藍 `#1B3065`＋湖水藍 `#4DAAC0`＋標誌藍 `#1B6CA5`，僅限名片。

## 9. 文案

| 面向 | 規範 |
|---|---|
| 對象與人稱 | 原廠、經銷商、通路採購、夥伴、求職者；「我們／威柏」對「貴公司／您」；招募可用「你」 |
| 語調 | 沉穩、具體、有數據；不喊口號、不促銷、不堆驚嘆號；「對市場謙卑而敬畏，對商品與供應鏈的每個環節自信而堅定」 |
| 證據 | 成立 2015、500+ 連鎖據點、11 個主流電商平台、50+ 經銷品牌、2022 年營收破億、北中南專櫃、三年供應鏈重構 |
| 關鍵詞 | 供應鏈賦能、全通路供應鏈節點、品牌落地、被看見・被喜歡・被信任、數據為本、服務先行、夥伴（不用「員工」） |
| 引述 | 只引總經理黃冠博；格式「威柏科技總經理黃冠博表示：『…』」 |
| 新聞稿 | 第一次寫全名「威柏科技貿易有限公司（以下簡稱『威柏科技』）」；文末新聞聯絡人、電話分機、信箱 |
| 禁用 | Emoji、網路流行語、「最強」以外的絕對化形容 |

### 品牌敘事七段（公司簡介、簡報首頁、採訪都照此順序）

1. 草根起家：創辦人 19 歲夜市擺攤，2015 成立威柏 —「草根從不是弱勢，而是一種扎根前線的能力。」
2. 敬畏市場、數據為本：市場趨勢資料庫 —「資料不是冷冰冰的報表，而是企業理解世界的語言。」
3. 服務先行：保固、品控、維修、通路教育、回訪 —「銷售成績不僅是成績單，更是與顧客關係的開始。」
4. 三年重構：倉儲標準化、電商 SOP、售後品保、數據平台；從代理到供應鏈節點 —「真正的對手其實是市場變化的速度。」
5. WEI 宇宙三軸：體驗 WEiZ｜科技 WEIBO｜未來 WEILIFE —「未來不會輕鬆，但卻是最值得投入的十年。」
6. 人才是夥伴：職務手冊與組織結構 —「堅持，是很重要的核心文化，把事情做好與做完是完全不同的兩件事。」
7. 決勝 2026–2030：速度、規模、工具、新型態市場 —「對於市場，我們總是謙卑而敬畏；但對於商品與供應鏈的每個環節，我們自信而堅定。」

範例一句話介紹：「WEIBO 威柏科技是台灣 3C 品牌總代理，以供應鏈管理、全通路營運與資訊系統整合，協助國際品牌在 500+ 實體據點與 11 個主流電商平台快速落地。」

## 10. 圖示與影像

- 圖示：Lucide 線條，1.75–2px，圓角 2px，主色或白色；尺寸 16／24／32／48。Artifact 環境無 CDN 時手寫 SVG。
- 影像主題：「看得見的落地能力」——倉儲、物流、專櫃現場、團隊作業、通路陳列；不是產品情境照（那是 WEiZ 與代理品牌的）。
- 人物為工作中的團隊側寫，不看鏡頭；自然光或均勻室內光；中性偏冷、低飽和；水平線要正；禁 HDR、生活風濾鏡、疊漸層、代理品牌 Logo 當主體。
- 目前無自有影像庫（v1.1 待辦），使用外部素材時依上述審核。
